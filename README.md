# Stack

ゆれる長方形のブロックを積み上げていく、バランス積み上げゲームです。`index.html` 1ファイルで動きます（ブラウザで開くだけ）。

## 遊び方

- タップ／クリック／スペースキー（Enter）でブロックを落とします。
- どの段でも、その上にあるブロック全体の重心が下のブロックの幅から大きく外れると、そこから倒れてゲームオーバーです。
- 下のブロックにまったく重ならなかった場合もミスになります。
- 真ん中に近いほど高評価です。
  - **PERFECT**：ズレ 2px 以下
  - **GOOD**：ズレ 5px 以下
  - どちらもコンボが続きます。それ以外はコンボがリセットされます。
- ベストスコアはブラウザの localStorage に保存されます。

## ゲームの流れ

- 高く積むほど背景が、青空、夕焼け、夜、宇宙、惑星、銀河、ブラックホールと変わっていきます。
- 速度は10段目で少し上がり、21段目以降は1段ごとに上がって、ブラックホールが現れる130段目で最高速度になります。
- 21段目以降はブロックの幅がランダムに変わることがあります。

## 開発用

URL に `?dev` を付けると「開始段数」の入力欄が表示されます。`?start=30` のように付けると、欄が出て30段が入った状態になります。通常は非表示です。

## 調整できる定数

`index.html` の先頭付近にあります。

| 定数 | 内容 |
| --- | --- |
| `PERFECT_TOL` / `GOOD_TOL` | PERFECT / GOOD のズレ幅（px） |
| `STABILITY_SLACK` | 倒れる判定の遊び（支えの幅に対する割合） |
| `SPEED0` / `SPEED_MAX` | 初期速度 / 最高速度 |
| `BLACKHOLE_LEVEL` | ブラックホールが現れ始める段（ここで最高速度） |

## 履歴

`log/` に各バージョンのスナップショットと `history.md` があります。
